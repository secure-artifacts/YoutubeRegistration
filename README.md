# 📹 YouTube 视频登记助手

在看 YouTube 时，一键把视频信息登记到 Google 表格。支持三端：

| 平台 | 形式 | 特点 |
|------|------|------|
| 💻 电脑 (Chrome) | 浏览器扩展 | 观看时直接弹窗登记 |
| 🤖 Android | 原生 App | 屏幕悬浮窗，可叠加在任意 App 上方 |
| 🍎 iOS | PWA 网页版 | 添加到主屏幕，配合快捷指令使用 |

---

## ⬇️ 下载

前往 [Releases](../../releases/latest) 页面下载最新版本：

- `YouTube登记助手-Chrome插件.zip` — 电脑版 Chrome 扩展
- `YouTube登记助手-Android.apk` — Android 悬浮窗 App
- `YouTube登记助手-iOS.html` — iOS / 手机浏览器 PWA

## 安装说明

### 💻 电脑版（Chrome 扩展）

1. 下载并解压 `YouTube登记助手-Chrome插件.zip`
2. 打开 Chrome，地址栏输入 `chrome://extensions`
3. 右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选择解压后的文件夹
5. 扩展栏出现 📹 图标即安装成功

### 🤖 Android 版

1. 下载 `YouTube登记助手-Android.apk`
2. 手机打开文件，安装（需允许「安装未知来源应用」）
3. 打开 App → 授权悬浮窗 → 填写 Google Apps Script URL → 启动
4. 按 Home 键回到主屏幕，屏幕边角出现 📹 悬浮按钮
5. 打开 YouTube，点击悬浮按钮即可登记

### 🍎 iOS 版（PWA）

1. 下载 `YouTube登记助手-iOS.html`，或直接用 Safari 打开本仓库的 mobile.html
2. 点击 Safari 底部「分享」→「添加到主屏幕」
3. 主屏幕出现图标，像 App 一样使用
